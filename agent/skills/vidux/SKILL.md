# Vidux

Vidux owns the plan-first operating contract:

- Find the canonical plan before adding work.
- Resume in-progress rows before creating duplicates.
- Pair source changes with proof and durable evidence.
- Publish handoffs through append-only ledger rows.
- Re-prove merged trunk before claiming done.

Public Vidux source intentionally ignores local private project plans. Keep that
boundary intact while allowing local checkouts to read ignored plans for
operator context.

Verification command: `npm run eve:capabilities -- --json`.
