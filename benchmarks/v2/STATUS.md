# Benchmark v2 Status

`vidux-cockpit-v2` is retired and non-runnable.

The frozen manifest remains in the repository as an inspectable negative
artifact. It is valid as a record of the preregistered rules, but those rules do
not define a fair or reproducible public run. The CLI therefore refuses fixture
sealing, packet issuance, and scoring under this protocol id.

The concrete blockers are recorded in `STATUS.json`. They require
outcome-determining changes to provider matching, oracle adjudication, schedule
completeness, receipt verification, and hard budgets. The manifest's amendment
policy requires those corrections to use a new protocol id.

No fixture release or raw rows exist. Verified net-win scenario classes remain
zero, and no Vidux superiority claim is supported by v2.
